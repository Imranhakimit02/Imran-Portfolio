# Imran Hakim portfolio

This website uses plain HTML, CSS and JavaScript. No React, Tailwind runtime, npm installation or build step is required.

Open http://localhost/my_portfolio/ with XAMPP Apache running, or open index.html directly in a browser.

Edit the pages directly:
- index.html: overview, experience, education, skills and internship journal
- project.html: project cards and native case-study dialogs
- certs.html: awards and professional learning
- resume.html: styled interactive resume and original PDF viewer
- contact.html: contact information
- styles.css: shared design tokens, responsive layouts and light/dark themes
- app.js: menu, theme persistence, filters, dialogs, clipboard, resume format and detail toggles
- assets/Imran-Hakim-Resume.pdf: original PDF

All text, projects and internship weeks are present in the HTML and readable without JavaScript. JavaScript adds interactive controls. The PDF viewer depends on the browser's PDF support and includes a direct link. Clipboard access includes a fallback for local-file or restricted browser contexts.

The previous React development files are retained in framework-backup.zip for reference. They are not used by the plain HTML website.
